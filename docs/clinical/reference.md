# OrthoVision AI: Clinical Reference

## Orthopedic Measurements
- **Cobb Angle**: Automated spinal curvature analysis.
- **HKA Angle**: Hip-Knee-Ankle mechanical axis.
- **NSA**: Femoral Neck-Shaft Angle.
- **mRUST**: Modified Radiographic Union Scale for Tibia.

## Fracture Classification
- **AO/OTA**: Automated morphological classification (e.g., 32-C).
- **Non-Union Risk**: Bayesian estimation based on stability and BMD.

## Bone Health
- **vBMD**: Volumetric Bone Mineral Density in mg/cm^3.
- **T-Score**: Standardized osteoporosis screening.
- **Fragility Index**: Radiomics-based micro-architecture assessment.
